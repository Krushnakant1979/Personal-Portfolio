# Krushnakant Rutele - Personal Portfolio

A modern, production-ready personal portfolio website built with a Next.js frontend and an Express/MongoDB backend.

## Features

- **Modern Design:** Dark-mode first, glassmorphism UI, Framer Motion animations.
- **Full-Stack:** Next.js 14 App Router frontend, Express REST API backend.
- **Database:** MongoDB via Mongoose.
- **Admin Dashboard:** Secure login (JWT HTTP-only cookies) to manage projects and view contact submissions.
- **SEO Optimized:** Metadata, OpenGraph tags, sitemap, robots.txt, semantic HTML.
- **Responsive:** Mobile-first layout.

## Prerequisites

- Node.js (v18+)
- MongoDB (Local or Atlas)

## Getting Started

### 1. Clone & Install Dependencies

```bash
# Frontend
cd client
npm install

# Backend
cd ../server
npm install
```

### 2. Environment Variables

**Backend (`server/.env`):**
Create a `.env` file in the `server` directory using `.env.example` as a template:
```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/krushna_portfolio
JWT_SECRET=your_super_secret_jwt_key
CLIENT_URL=http://localhost:3000
```

**Frontend (`client/.env.local`):**
Next.js works out of the box with the default settings pointing to `http://localhost:5000`.

### 3. Seed the Database

Populate the database with your admin account and sample projects:

```bash
cd server
node src/seed/index.js
```
*Note: Default Admin credentials generated by the seed script are `krushnakantrutele1979@gmail.com` and password `admin123`.*

### 4. Run the Development Servers

Open two terminal tabs.

Terminal 1 (Backend):
```bash
cd server
npm run dev
```

Terminal 2 (Frontend):
```bash
cd client
npm run dev
```

Visit `http://localhost:3000` to view the portfolio.

## Deployment

- **Frontend (Next.js):** Deploy seamlessly to [Vercel](https://vercel.com).
- **Backend (Express):** Deploy to Render, Railway, or Heroku. Make sure to set environment variables.
- **Database:** Use MongoDB Atlas for production.
